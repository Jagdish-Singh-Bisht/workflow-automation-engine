Help & Getting Started

Follow this guide to configure your account and start creating automated workflows.

1. Getting Started

Follow these steps to start using the Automation System:

  1. Create your account and log in.
  2. Configure the services required by your workflow.
  3. Add email recipients if your workflow sends emails.
  4. Create a workflow.
  5. Run the workflow manually or configure a trigger.
  6. Check the execution history to see the result.

2. Configure Connected Services

Configure only the services required by your workflows.

Email

Email credentials are used to determine which email account sends messages from your workflows.

Required:
  • Email / SMTP username
  • App password
Steps:
  1. Open Profile.
  2. Open Connected Services.
  3. Select Email.
  4. Enter your email address.
  5. Enter your app password.
  6. Save the credentials.
Configure Email
New to email app passwords?

The App Password is not your normal Gmail password. It is a special password generated by Google for applications that need to access your email account.

Create a Google App Password
Gemini

Gemini can be used by AI-enabled workflows for processing and generating content.

Required:
  • Gemini API key
Steps:
  1. Open Profile.
  2. Open Connected Services.
  3. Select Gemini.
  4. Enter your API key.
  5. Save the credential.
Configure Gemini
Where do I get a Gemini API key?

You can create an API key through Google AI Studio. This key allows the application to use Gemini through the API.

Open Google AI Studio
WhatsApp

WhatsApp messaging is provided through Twilio.

Required:
  • Your WhatsApp number
  • Twilio Account SID
  • Twilio Auth Token
Steps:
  1. Open Profile.
  2. Open Connected Services.
  3. Select WhatsApp.
  4. Enter the required credentials.
  5. Save the credentials.
Configure WhatsApp
Where do I get Twilio credentials?

Create or access your Twilio account to obtain your Account SID and Auth Token.

Open Twilio Console

3. Configure Email Recipients

Email recipients are the people who receive emails generated by your workflows.

You can:
  • Add multiple recipients.
  • Activate or deactivate recipients.
  • Delete recipients you no longer need.
Only active recipients will receive emails from your email workflows.
Remember:
Email Credentials determine who sends the email.
Email Recipients determine who receives the email.
Steps:
  1. Open Profile.
  2. Open Email Recipients.
  3. Add the recipient's name and email address.
  4. Keep the recipient Active if they should receive emails.
  5. Deactivate the recipient when you don't want them to receive emails.
Manage Email Recipients

4. Create Your First Workflow

A workflow consists of nodes that process information step by step.

INPUT → AI / PROCESS → OUTPUT
Steps:
  1. Open Workflows.
  2. Create a new workflow.
  3. Configure the required nodes.
  4. Select the required output service.
  5. Run the workflow.
Go to Workflows

5. Schedule a Workflow

Triggers allow workflows to run automatically according to a schedule.

Steps:
  1. Open Triggers.
  2. Select the workflow you want to schedule.
  3. Enter a valid Cron expression.
  4. Enable the trigger.
  5. Save the trigger configuration.
Example: 0 */5 * * * *
Runs the workflow every 5 minutes.
Manage Triggers

6. Check Execution History

Every workflow execution is recorded so that you can inspect its status and result.

  1. Open Executions.
  2. Select an execution.
  3. Review the input, output, status and execution time.
View Executions

7. Common Problems

Email is not being sent
  • Check that Email credentials are configured.
  • Check that the app password is correct.
  • Check that at least one recipient is Active.
  • Check that Email is enabled for the workflow.
Gemini workflow is not working
  • Check that a Gemini API key is configured.
  • Check the AI node configuration.
WhatsApp is not sending
  • Check your Twilio Account SID.
  • Check your Twilio Auth Token.
  • Check your WhatsApp number.
  • Check that WhatsApp is enabled.

8. Security

Never share your:
  • Email app password
  • Gemini API key
  • Twilio Account SID
  • Twilio Auth Token

These credentials are used by the application to connect to external services on your behalf.
